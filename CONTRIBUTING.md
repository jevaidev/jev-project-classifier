# Contributing

Contributions should improve collection, classification rubrics, tests, or review ergonomics.

## Requirements

- Keep GitHub Star ranking deterministic and independent from Jev output.
- Preserve original source URLs and collection timestamps.
- Add tests when changing rubric interpretation or thresholds.
- Do not add automatic publication, merging, outreach, or repository mutation.
- Do not present community work as an official TypeSafe AI release.
- Treat model suggestions and submitted text as untrusted until a maintainer reviews them.

Run `npm run check` before proposing a change.
